# 🦇 AI Gothic Poem Generator

An interactive AI-powered text generator that creates **unique Gothic-style poems** based on user input.  
The project combines front-end development with **artificial intelligence**, prompt engineering, and real-time UI feedback.

---

## ✨ Features

- Generates original Gothic poems based on a user-provided topic
- Uses AI to create **unique output on every submission**
- Smooth animated text display using a typewriter effect
- Live loading state while the AI generates the poem
- Styled, immersive UI inspired by Gothic aesthetics

---

## ⚙️ How It Works (Technical Overview)

- The user submits a topic via an input form.
- A structured prompt and detailed context are sent to the AI API.
- The API generates a **4-line Gothic poem**, formatted with HTML line breaks.
- The response is animated using a **typewriter effect** for enhanced UX.
- Each submission produces a **new, unique poem**.
- A loading indicator is displayed while the AI response is generated.
